## 兼容规则

- 这是一套创作坐标，不是临床量表或智力排名。
- 新任务从开放本体选择能解释当前人物选择的最小充分 facet，不按数量填表。
- 旧编号和 id 仍可作为 alias 使用，但必须映射到开放本体的当前 domain/facet。
- 未知必须写 `unknown`，不能用类型刻板印象补齐。
- 每个被选中的维度都要落到动作、语言、关系、选择、代价或弧线。
- 可用 `low / medium / high`、两端谱系或自然语言描述；不要制造虚假精确分数。

## 维度组合方法

优先找承重组合，而不是孤立高低分：

- `threat-sensitivity + control-adaptation-style + trust-threshold`：控制型保护者或偏执管理者。
- `status-recognition-drive + shame-guilt-orientation + public-mask`：成就型、名誉型或羞辱敏感人物。
- `belonging-attachment-drive + boundary-reciprocity + self-deception`：讨好、占有、牺牲或依赖型关系动力。
- `moral-reasoning + moral-boundary + threshold-choice`：道德困境和高潮选择。
- `false-story + change-resistance + transformation-direction-cost`：完整人物弧线。

## 禁止用法

- 不凭本目录评分诊断现实人物。
- 不把“展开全部 50 行”当作完整人物或高质量分析。
- 不继续向本文件追加新维度；扩展进入 `character-intelligence-ontology.md` 及对应知识 reference。
- 不把维度当善恶、高低或正常异常排名。
- 不用一个场景推断所有关系和所有时期。
- 不为了矩阵完整而创造正文不存在的证据。
