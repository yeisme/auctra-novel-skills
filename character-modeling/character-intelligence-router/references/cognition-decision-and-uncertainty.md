# 认知、决策与不确定性知识卡

用于设计人物如何注意、建模、判断、修正和下注。这里的机制是创作坐标，不是智力测验。来源编号见 `source-ledger.md`。

## 知识卡

| 机制 | 来源事实层 | 创作解释层 | 创作规则层 |
| --- | --- | --- | --- |
| 有限信息处理 | 判断会受可用信息、注意和工作记忆限制，人物不可能同时处理全部线索。[INT-05] | 人物的错误可以来自“没看见”而非“看不懂”。 | 每次关键决定先列角色当时实际可用的信息，不把作者知识偷渡给人物。 |
| 注意过滤 | 目标、专业经验、威胁和情绪会改变什么更显眼。[INT-05][INT-08] | 医生、骗子、母亲和逃犯进入同一房间会看到不同世界。 | 为承重场景写“先看到三项、最后才看到一项、完全忽略一项”。 |
| 心智模型 | 人会用关于系统、他人和因果关系的内部模型预测结果；模型可能有用但不完整。 | 高能力人物也可以因模型过时而稳定犯错。 | 不写“聪明/愚蠢”，写其模型包含哪些变量、遗漏哪些反馈。 |
| 启发式 | 快速判断常依赖熟悉度、代表性、可得性、锚点等简化规则。[INT-05] | 同一启发式在熟悉环境中是专长，在新环境中可能变成偏误。 | 给人物一条常用快捷规则，并设计一个它有效、一个它失效的场景。 |
| 因果归因 | 人可能把结果解释为自己、他人、情境、制度、运气或命运造成。[INT-05] | 归因决定内疚、报复、改革、放弃或求助。 | 同一失败至少写两种可能归因，并让人物选择其中一种承担后果。 |
| 概率直觉 | 人物对可能性和基率的理解可精确、模糊、故事化或过度自信。 | “我有预感”可能是模式识别，也可能是忽略基率。 | 写人物如何表达不确定：数字、等级、故事、绝对词、回避或交给权威。 |
| 证据阈值 | 不同决定需要不同程度的证明；代价、身份和关系会改变阈值。 | 人物可能对敌人要求零证据，对自己人要求不可反驳证据。 | 分别定义相信、行动、公开指控和道歉所需的证据阈值。 |
| 损失框架 | 同一结果被看作获得还是损失时，选择倾向可能不同。[INT-05] | 守住已有地位的人与争取新机会的人会承担不同风险。 | 把关键选择分别重写成“能得到什么”和“会失去什么”，检查人物是否改变。 |
| 时间折扣 | 即时收益与远期收益的权重因情境、资源安全和人物习惯而异。 | 贫困、病痛、追杀或成瘾情境会让长期规划变得昂贵，不等于缺乏品格。 | 先写角色是否相信未来存在，再判断其“短视”。 |
| 沉没成本与承诺 | 已投入的时间、身份、声誉和牺牲会让退出更难。 | 悲剧人物常不是看不见失败，而是不愿承认过去牺牲无意义。 | 退出成本必须包含心理、关系和公开身份，不只写金钱。 |
| 决策阈值 | 有些人物需要充分确定才行动，有些人物用行动换信息。 | 决断速度与正确率、勇气或领导力不是同一属性。 | 写出“何时等待、何时试探、何时不可逆下注”的三层阈值。 |
| 元认知修正 | 人可以观察自己的错误、寻求反证、换模型，也可能只擅长事后解释。[INT-05] | 自我分析很多不等于真正可修正。 | 成长证据必须是下一次选择规则改变，不是一次漂亮复盘。 |
| 社会性认知 | 对他人意图的判断依赖关系史、身份、权力与文化脚本。 | 对同一句话的误读可能来自关系模型，而非语言理解能力。 | 分析决定前同时检查“我认为他是谁”和“我认为他想从我这里得到什么”。 |
| 集体决策 | 组织中的信息分布、地位、沉默和责任分散会改变个体判断。 | 聪明成员也可能在坏流程中产出坏决定。 | 群体场景分别记录谁知道、谁能说、谁会被信、谁承担错误。 |

## 决策指纹

不要给人物贴“理性/感性”标签，改用以下组合：

```text
attention_filter
+ mental_model
+ evidence_threshold
+ uncertainty_language
+ time_horizon
+ gain_loss_frame
+ identity_commitment
+ relationship_cost
+ action_threshold
+ correction_rule
```

## 验证场景阶梯

1. 低风险信息不足：人物会追问、猜测、试探还是等待？
2. 熟悉领域：快捷规则是否体现经验？
3. 陌生领域：同一规则怎样失效？
4. 身份受威胁：证据标准是否双重化？
5. 不可逆损失：人物怎样权衡未来、关系与自我故事？
6. 反证出现：人物修正、合理化、攻击来源还是改变目标？

## 使用边界

- 不用教育程度、术语量、反应速度或职业直接推断智力。
- 不把偏误写成固定缺陷；先检查信息、激励、权力和时间压力。
- 不让“天才直觉”绕过可追溯的经验、错误和验证。
- 不用人物决策模型预测现实个人的危险性或法律责任。
