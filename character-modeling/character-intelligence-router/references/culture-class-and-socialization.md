## 文化阶层卡片

| 机制 | 事实层 | 创作解释层 | 创作规则层 |
| --- | --- | --- | --- |
| 文化 | 文化包含学习而来的价值、规范、符号、语言和实践，但任何社会内部都存在差异与变化。[SOC-01][UNESCO-01] | 角色共享一些符号，却可能因代际、地区、阶层和经历赋予不同意义。 | 禁止用一个国家或族群形容词完成整个人设。 |
| 价值与规范 | 价值说明被认为重要的事，规范规定特定情境中的可接受行为；实践可能偏离规范。[SOC-01] | 角色会公开维护规范、私下违反，或真诚相信却做不到。 | 同时写“应该怎样”“实际怎样”“被发现会怎样”。 |
| 符号与礼仪 | 服饰、礼物、称呼、空间、仪式和身体姿态会传递身份与关系。 | 一个小小礼仪错误可以暴露外来者或挑战者。 | 为关键社群设置三种可见信号及错误使用的后果。 |
| 社会化 | 家庭、同辈、学校、宗教、媒体和组织会教会人角色、规则与自我理解。[SOC-02] | 不同社会化来源可能互相冲突，形成双重生活或代际矛盾。 | 列出“谁教会他这条规则、用什么奖励或羞耻维持”。 |
| 家庭脚本 | 家庭既是亲密关系，也是角色、资源、代际与社会规范的制度场域。[SOC-06] | 同一家人可共享外部形象，却内部执行不同规则。 | 写家庭公开叙事、禁谈事件、继承/照料规则与例外成员。 |
| 物质阶层 | 收入、财产、住房、健康、安全、时间和风险承受力塑造机会。 | 富裕不仅提供消费，也提供失败缓冲；贫困不等于单一价值观。 | 写“犯同样错误时不同角色承担什么后果”。 |
| 教育与语言资格 | 教育、口音、词汇、证书、礼仪和品味可成为进入某些空间的门槛。 | 角色可能拥有能力却缺少被承认的表达方式。 | 设置一个需要“会做”与“会证明自己会做”同时满足的场景。 |
| 社会网络资源 | 认识谁、谁愿意引荐、谁能担保会影响机会。 | 角色可能把人脉视为正常互助，也可能视为不公。 | 给角色一次没有公开规则可走、只能靠介绍的机会。 |
| 社会分层 | 分层把资源、地位和机会不均等地分配，并与流动机制相连。[SOC-04] | 角色对制度的解释会取决于受益、受损、期望和比较对象。 | 区分客观位置、主观阶层认同和他人如何分类他。 |
| 流动 | 向上、向下、代际或地域流动会改变资源，也会制造归属与能力失配。 | 成功者可能同时害怕露怯、背叛出身或失去新身份。 | 写进入、被考验、返乡三种场景，观察不同 code-switching。 |
| 污名 | 某些身份或经历会被社会贬低，影响信息披露、机会和自我保护。 | 隐藏污名能换取安全，也可能造成亲密关系中的欺骗压力。 | 明确谁知道、谁能揭露、被揭露在哪个场域代价最高。 |
| 身份切换 | 人会在家庭、工作、同辈和公共空间调整语言、姿态与自我呈现。 | 切换可能是能力、疲惫来源、羞耻或生存策略。 | 给角色设计一处切换成功和一处切换失败。 |
| 制度位置 | 法律、学校、市场、职业、宗教和政府角色会给人不同资格与限制。[SEP-01] | 角色的个人愿望可能被申请、许可、证明、监护或程序卡住。 | 把抽象制度写成具体门槛、表格、守门人、等待和申诉。 |
| 交叉情境 | 同一身份在不同阶层、地域、年龄和组织中含义不同。 | 一个角色可能在某场域占优势、在另一场域受限。 | 为角色至少设置两个地位相反的场域，禁止单轴受害/特权叙事。 |
| 文化变化 | 迁移、技术、战争、市场、教育和社会运动会改变规范与身份边界。[SOC-08] | 代际冲突常是不同变化速度的冲突，不只是年轻/保守标签。 | 写同一传统对祖辈、父母、青年和外来者的不同功能。 |

## 失配场景库

- 不知道该向谁先打招呼或谁可以被直呼其名。
- 有钱但缺少被认可的品味、口音、证书或家族。
- 掌握规则却拒绝表演，因而被误判无知。
- 向上流动后回到旧社群，被视为炫耀或背叛。
- 在亲密关系中无法持续维持公共身份切换。
- 制度规则名义中立，但申请时间、证明材料或关系入口造成差异。

## 使用边界

- 文化多样性不是“每个群体都有固定习俗清单”。
- 现代身份标签、阶层术语和法律概念不能无验证地投射到历史故事。
- 规范、统计倾向和个人行为必须分开。
- 边缘身份角色仍应拥有欲望、能力、错误和矛盾，而不只是代表性负担。
