# 身体、感官与习惯知识卡

用于把人物心理转成可观察、可写、可拍和可表演的身体行为。来源编号见 `source-ledger.md`。

## 知识卡

| 机制 | 来源事实层 | 创作解释层 | 创作规则层 |
| --- | --- | --- | --- |
| 具身认知 | 具身认知讨论身体、行动与环境如何参与认知，而非把心智视为只在头脑内运行。[INT-08] | 人物通过移动、触摸、工具和空间安排来思考。 | 关键推理至少寻找一种身体或环境操作，不用纯内心解释包办。 |
| 感官优先级 | 人物对视觉、声音、触觉、气味、味觉、温度、平衡和身体内部感受的关注不同。 | 感官选择使视角具有职业、经历和状态差异。 | 为 POV 定义优先感官、盲点感官和压力下突然显著的感官。 |
| 内感受 | 饥饿、心跳、呼吸、疼痛、恶心、疲劳等内部信号参与情绪与决策。 | 人物可能精确觉察身体，也可能只在失控后发现。 | 不把身体信号自动解释成情绪；保留误读和延迟识别。 |
| 动作准备 | 身体会在行动前出现方向、张力、重心和距离变化。 | “准备逃跑”可以先于人物承认恐惧。 | 在重大选择前写一个微小但功能性的动作准备，不必解释。 |
| 姿势与节奏 | 姿势、步幅、手势、呼吸和动作速度受习惯、状态、身份与环境影响。 | 同一人物在家、办公室、医院和敌人面前拥有不同身体权限。 | 设计基线、角色场合变化和压力破裂三种节奏。 |
| 空间使用 | 座位、门口、距离、退路、高低和视线体现安全、权力和关系。 | 控制空间可能是职业习惯、情绪调节或统治行为。 | 场景阻塞时先画谁能靠近谁、谁守出口、谁占中心。 |
| 触摸边界 | 谁能触碰、触碰哪里、由谁发起、何时撤回，具有关系与文化含义。 | 亲密人物也可能在公开场合拒绝触摸；敌人可用礼仪触碰夺权。 | 为每段关系定义允许、功能性、安慰性、禁区与越界触摸。 |
| 物件延伸 | 工具、衣物、武器、手机、书、药物和纪念物可以扩展能力、身份与记忆。 | 人物丢失关键物件时可能像失去一部分能动性。 | 物件必须有使用史、维护方式和失去后的行为后果，不只做象征。 |
| 日常程序 | 重复程序降低决策成本，也维持安全、身份和控制感。 | 打破程序可比激烈对白更快显示危机。 | 写普通日的一条程序、秘密程序和压力下被破坏的程序。 |
| 技能痕迹 | 长期训练会进入姿势、视线、手部动作、风险判断和空间选择。 | 退休、伪装或失忆不一定抹掉身体化专业习惯。 | 职业研究要转成动作规则，不用术语堆砌代替熟练度。 |
| 疲劳与疼痛 | 疲劳、疼痛和疾病状态会改变注意、耐心、动作、风险和社交能力。 | 人物在资源耗尽时不是简单“性格变坏”，而是可用调节能力下降。 | 高压连续场景记录睡眠、饮食、伤势、药物和恢复，不让身体每章复位。 |
| 自我安抚习惯 | 重复动作、呼吸、整理、触摸物件或寻求特定感觉可能降低唤醒。 | 安抚动作可以被他人识别、打断、模仿或利用。 | 给习惯具体功能和成本，避免把随机小动作当人物深度。 |
| 身体羞耻与展示 | 人物会管理身体可见性、能力、年龄、伤疤、服饰与欲望。 | 展示或遮蔽可能与身份、阶层、亲密和权力相关。 | 不将身体差异自动写成创伤；先确定人物自己的意义。 |
| 环境耦合 | 光、噪音、拥挤、天气、地形和可用工具会改变行为可能性。 | “同一个人”在不同环境中拥有不同能力与耐受。 | 场景设计同时写环境提供的行动机会和剥夺的行动机会。 |

## 习惯不是装饰

一个值得保留的习惯至少连接三项：

```text
trigger
+ immediate function/reward
+ observable sequence
+ interruption response
+ relationship meaning
+ long-term cost
```

若动作只为了让角色“显得特别”，没有功能、关系或后果，应删除。

## 媒介转译

### 小说

- 用人物注意到的感觉和动作改变 POV，而非统一作者描写。
- 控制解释量，让身体信号可以先于人物理解。
- 记录身体连续性：伤、疲劳、衣物、物件和空间记忆。

### 剧本

- 只写可拍、可听、可表演的动作和环境变化。
- 避免给演员不可执行的抽象指令，如“显得复杂”。
- 每个动作应影响节奏、空间、物件、对手或下一句对白。

## 验证场景阶梯

1. 普通程序：无人观看时身体怎样运作？
2. 进入陌生空间：先找什么、避开什么？
3. 亲密靠近：距离和触摸规则怎样变化？
4. 技能调用：专业如何进入动作而非说明？
5. 疲劳疼痛：旧习惯失效后暴露什么？
6. 习惯被打断：人物重新获得控制还是升级冲突？

## 使用边界

- 不从单个姿势、眼神或小动作确定性读取情绪或说谎。
- 不把残障、疾病、体型、年龄或神经差异当人物缺陷模板。
- 不滥用“微表情识谎”等缺乏情境的确定性结论。
- 身体动作必须尊重具体时代、职业、文化、环境和可访问性。
