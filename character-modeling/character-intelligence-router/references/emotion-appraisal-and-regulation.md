# 情绪评估、表达与调节知识卡

用于把“他很愤怒/冷漠/敏感”展开为事件评估、身体变化、行动冲动、表达、调节、关系后果和恢复。来源编号见 `source-ledger.md`。

## 情绪回路

```text
event
  -> attention
  -> appraisal
  -> body activation
  -> action urge
  -> expression or concealment
  -> regulation strategy
  -> social consequence
  -> recovery / afteremotion
```

## 知识卡

| 机制 | 来源事实层 | 创作解释层 | 创作规则层 |
| --- | --- | --- | --- |
| 事件评估 | 情绪不仅取决于事件，也取决于人物如何判断其目标相关性、责任、可控性和意义。[INT-04][INT-06] | 同一取消约会可被理解为轻视、危险、自由、羞辱或偶然。 | 先写人物对事件的解释，再命名情绪；不要从事件直接跳到情绪。 |
| 情绪基线 | 人物在无明显事件时也有常见唤醒水平和情绪温度，但会受睡眠、身体和环境影响。 | 基线影响场景入场速度和他人对人物的误读。 | 基线只描述默认起点，不禁止人物拥有反常时刻。 |
| 情绪粒度 | 人们区分和命名感受的精细程度不同。 | 只能说“烦”的人物与能区分失望、羞耻、嫉妒和悲伤的人会采取不同修复。 | 设计人物可使用的情绪词汇与其身体化表达，不把词少等同感受少。 |
| 行动冲动 | 情绪常伴随接近、逃离、攻击、冻结、寻求照料、隐藏或修复的冲动。 | 人物可以感到一种冲动却选择相反行动，产生自控或撕裂。 | 分开写“想做什么”和“最终做什么”。 |
| 表达规则 | 文化、阶层、职业、性别规范和权力关系会影响哪些情绪可公开表达。 | 强者可以公开发怒，弱者可能只能显得笨拙、疲倦或讽刺。 | 同一情绪分别写私下、对上、对下、对亲密对象的表现。 |
| 情境选择 | 人物可通过接近或避开某些人和环境调节情绪。[INT-04] | 总不参加聚会可能是调节策略，不只是内向标签。 | 写出人物预先避开的场景，以及避开带来的长期关系成本。 |
| 情境修改 | 人物可改变环境、规则、话题或距离以改变情绪轨迹。[INT-04] | 控制座位、关门、安排流程可能是隐性情绪管理。 | 将“控制欲”拆为它试图降低的具体情绪和不确定性。 |
| 注意部署 | 转移、聚焦或反复咀嚼会改变情绪持续时间。[INT-04] | 盯住一个细节可让人物镇定，也可加剧执念。 | 给人物一种注意习惯，并展示它在不同情绪中的双刃效果。 |
| 认知重评 | 改变对事件的理解可改变情绪轨迹。[INT-04] | 重评可以是成熟修正，也可以变成粉饰、合理化或自我背叛。 | 检查新解释是否吸收证据，还是只为了不感受。 |
| 表达抑制 | 压住可见表达不等于消除内在体验，可能产生认知或关系成本。[INT-04] | 冷静人物可以在身体、记忆、节奏和后续行为中泄露余波。 | 每次抑制都写“成功隐藏了什么、泄露了什么、之后付出什么”。 |
| 共调节 | 他人的声音、触摸、结构、见证或可靠行动会参与情绪恢复。 | 独立人物也可能只有在某个对象前才能放松，形成关系奖赏和风险。 | 指定谁能使其恢复、谁会加剧、人物是否愿意承认这种依赖。 |
| 恢复与余波 | 情绪峰值结束后可能留下疲劳、羞耻、空虚、警觉、内疚或报复计划。 | 场景结束不等于人物复位；余波维持连续性。 | 每个高压场景写下一小时、下一天和下一次遇见触发者的状态。 |
| 二级情绪 | 人物可能对自己的第一情绪产生羞耻、愤怒、恐惧或骄傲。 | “我不该嫉妒”会把嫉妒转成冷漠、攻击或自罚。 | 把初级情绪和人物对它的评价分开。 |
| 调节灵活性 | 没有一种策略在所有场景都最好；有效性取决于可控性、时间和社会后果。[INT-04] | 同一人物的成长可以是学会换策略，而非永远冷静。 | 让成长通过策略适配性体现，不通过情绪消失体现。 |

## 情绪一致性不是反应相同

保持一致的是机制，而非表面表现：

```text
similar appraisal
+ relationship-specific display rule
+ available regulation strategy
+ current body/resource state
= contextually different but explainable behavior
```

## 验证场景阶梯

1. 轻微触发：人物是否觉察并命名？
2. 公开场合：表达规则怎样改变外显？
3. 亲密关系：谁能看到未调节状态？
4. 策略失效：旧调节方式造成什么代价？
5. 多重情绪：人物能否同时爱、恨、怕和内疚？
6. 恢复：高峰结束后人物怎样回到关系与行动？

## 使用边界

- 不把少表情、少语言或高控制直接等同没有情绪。
- 不把宣泄自动写成健康，也不把抑制自动写成病态。
- 不诊断情绪障碍、创伤反应或神经类型。
- 涉及现实自伤、危机或临床风险时，不使用文学模板替代专业支持。
