## 群体组织卡片

| 机制 | 事实层 | 创作解释层 | 创作规则层 |
| --- | --- | --- | --- |
| 群体成员资格 | 群体通过身份、接触、目标、边界和相互认可形成；成员资格可能正式或非正式。[SOC-03] | “自己人”决定谁获得信息、宽容和牺牲资格。 | 写加入仪式、成员特权、边界人物和退出后果。 |
| 共同意向 | 集体行动需要某种“我们在一起做什么”的协调，但成员理解可不完全相同。[SEP-03] | 群体可在口号一致时目标不同，也可在目标一致时互不信任。 | 分别写公开共同目标和各派对目标的解释。 |
| 角色分化 | 群体会形成任务角色、情感角色、象征角色和边缘角色。 | 正式领袖不一定是安抚者、执行者或意见中心。 | 给每个承重人物一个群体功能，避免全员都只提供观点。 |
| 群体规范 | 规范规定什么能说、谁能质疑、失败如何解释，并通过奖惩维持。[SOC-03] | 沉默可能是归属成本，而非真正同意。 | 写一条人人遵守却无人公开承认的规则。 |
| 从众与服从 | 从众、顺从与服从受群体压力、权威、情境和替代选择影响。[PSY-03] | 平时有原则的人在公开一致压力下也可能延迟异议。 | 区分私下认同、公开顺从和被迫执行，并设置匿名/公开两个版本。 |
| 领导 | 领导可以来自职位、能力、关系、象征或危机表现。 | 危机领袖和平时管理者可能不是同一人。 | 写平稳期与危机期两张影响力排名。 |
| 联盟与派系 | 成员会围绕共同利益、身份、关系、敌人或解释形成联盟。 | 派系并非纯粹恶意，常提供保护、信息和晋升。 | 为每个派系写共同利益、内部裂缝和不能公开的交易。 |
| 网络中心与桥接 | 高连接者、连接不同子群体的桥接者和控制入口的守门人拥有不同影响。[SKILL-04] | 最受欢迎的人不一定是最关键的桥接者。 | 画信任、信息、资源三张边图，寻找断开后网络分裂的人。 |
| 信息过滤 | 层级、守门人、恐惧和激励会让坏消息被延迟、修饰或消失。 | 领导者可能真诚却生活在被筛选的信息世界。 | 追踪一条坏消息从发现者到决策者每一步如何改变。 |
| 群体思维与沉默 | 高凝聚、强权威、外部压力和缺少异议渠道可能降低批判性讨论，但不能解释所有失败。[PSY-03] | 表面一致越强，角色越可能把怀疑变成私下玩笑或消极执行。 | 设置一个正式异议渠道并测试它是否真的安全。 |
| 官僚逻辑 | 组织通过角色、程序、记录和分工扩大协调，也可能产生责任分散和目标替代。[SOC-03][SEP-01] | 个人善意可能被程序阻挡，个人恶意也可能隐藏在“按规定办”。 | 把制度冲突写成具体表单、签字、等待、指标和责任链。 |
| 集体行动 | 共同利益不自动带来合作，成员会考虑成本、收益、信任、搭便车和他人是否参与。[SOC-08] | 人人都想改变，却可能没人愿意第一个承担风险。 | 写第一行动者、临界人数、背叛诱因和可见承诺。 |
| 替罪羊 | 群体可能把复杂失败归咎于一个安全目标，从而保护核心规则与领导。 | 被选中的人往往既足够内部又缺少保护。 | 写谁从单一归因中获益、谁保持沉默、真问题如何继续存在。 |
| 退出与发声 | 成员面对不满可以顺从、私下修补、公开发声、结盟或退出，选项受成本限制。 | 不能退出者的抵抗通常更间接。 | 给每个关键成员标注可用选项和使用后的第一层后果。 |
| 组织记忆 | 档案、仪式、老成员和传说保存组织经验，也会选择性遗忘。 | 新人听到的是“组织如何讲述过去”，未必是完整事实。 | 为同一历史事件写官方版本、老员工版本和被清除版本。 |

## 组织压力事件

- 资源突然减少，原先隐藏的优先级被迫公开。
- 外部威胁提高团结，也给清除异议者提供借口。
- 领袖失误后，继任、忠诚和责任归属同时爆发。
- 新成员带来外部网络或新规范，改变旧联盟。
- 机密泄露，让非正式实践必须接受公开解释。
- 一个边缘成员取得关键成功，挑战群体地位排序。

## 使用边界

- 不把群体行为归结为一个人格或一个术语。
- 正式组织图不能替代实际信息、信任与资源网络。
- 群体凝聚既可支持照料和合作，也可支持排斥和沉默。
- 现实组织安全、政治与劳动问题需要额外专业来源，不以创作卡片代替事实咨询。
