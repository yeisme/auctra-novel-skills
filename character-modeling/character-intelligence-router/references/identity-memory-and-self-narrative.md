# 身份、记忆与自我叙事知识卡

用于设计人物如何把经历组织成“我是谁”的故事，怎样在不同关系中表演角色，以及身份受威胁时如何修补连续性。来源编号见 `source-ledger.md`。

## 知识卡

| 机制 | 来源事实层 | 创作解释层 | 创作规则层 |
| --- | --- | --- | --- |
| 自我图式 | 人物会用关于自己的概括组织注意、记忆和期待。[INT-07] | “我是照顾别人的人”会让其更容易记住责任、忽略被照料需求。 | 写出一条自我句，以及三种它允许、禁止和看不见的行为。 |
| 叙事身份 | 叙事身份研究关注人怎样用内化且持续演变的人生故事赋予过去、现在和未来以统一与目的。[INT-01] | 人物不是经历的总和，而是对经历的选择、排列和意义化。 | 为同一经历写人物公开版本、私下版本和他无法承认的版本。 |
| 人生章节 | 人物会把生活分成“以前”“转折”“现在”“将来”等章节。 | 章节边界决定哪些旧行为被视为已死、复发或从未改变。 | 写出人物自认的章节标题，并检查正文是否提供转折证据。 |
| 高点与低点 | 被选择为高点或低点的记忆揭示价值、因果和身份。 | 同一客观事件可被一人视为成功、一人视为背叛。 | 不只问发生了什么，问“为什么这件事代表了我是谁”。 |
| 转折记忆 | 某些记忆被人物叙述为改变方向的节点。 | 人物可能把缓慢变化误写成一个神话时刻，以保护自我故事。 | 区分真实因果转折、象征性转折和事后重写。 |
| 记忆选择与重构 | 记忆不是完整录像；当前目标和身份会影响提取与解释。 | 不可靠叙述不必是故意撒谎，也可能是自我连续性工作。 | 冲突记忆要保留版本、证据与受益者，不急着选唯一真相。 |
| 角色身份 | 家庭、职业、阶层、宗教、组织和关系位置会附带义务与资格。 | 同一人物在“医生”“女儿”“移民”“领导”间可能无法同时合格。 | 每个承重角色写它要求什么、提供什么、禁止什么、由谁承认。 |
| 身份观众 | 身份需要面对某个真实或想象的观众被承认。 | 一个人可能只在已故父亲、孩子、敌人或公众眼中需要证明自己。 | 写出人物最重要的三名身份观众，以及各自拥有的判决权。 |
| 公开面具 | 面具是情境化自我呈现，不必等同虚伪。 | 面具可以保护隐私、履行职业、维护群体或操控他人。 | 写清面具服务的功能和无法持续时的泄漏点。 |
| 被指派身份 | 社会可能给人物贴上其不认同的身份、污名或角色。 | 冲突来自“我是谁”和“他们允许我是谁”的差距。 | 把自我认同、他人称呼、制度分类和实际待遇分开。 |
| 身份威胁 | 当能力、道德、归属、地位或连续性被否定时，人物会防御、证明、退出或重写故事。 | 一句普通批评可能因击中身份核心而引发过度反应。 | 写出威胁的是行为结果还是“我是什么人”的判决。 |
| 可能自我 | 人物对未来可能成为、害怕成为或应该成为的自我有想象。 | 希望与恐惧可以由同一未来身份驱动。 | 同时写 desired self、feared self、expected self 和 impossible self。 |
| 被否认的自我 | 人物会排除与主叙事不兼容的欲望、能力或历史。 | 阴影不必邪恶，也可能是温柔、依赖、野心或普通生活。 | 设计一个别人准确看见而人物立即否认的部分。 |
| 连续性修补 | 新事实冲击自我故事时，人物会吸收、例外化、责怪、赎罪或重写过去。 | 成长、堕落和自欺都可视为不同的叙事修补。 | 高潮后必须说明人物怎样重新讲述旧事件，而不只写行为改变。 |

## 身份张力类型

- `claimed–assigned`：自我认同与社会分类冲突。
- `role–role`：两个重要角色义务冲突。
- `past–present`：旧自我仍被他人记住。
- `public–private`：面具与私下欲望冲突。
- `actual–ideal`：实际行为违背理想自我。
- `desired–feared`：渴望的未来同时像最害怕的人。
- `individual–collective`：个人故事与家庭、民族、组织叙事冲突。
- `memory–evidence`：身份依赖的记忆被新证据动摇。

## 验证场景阶梯

1. 自我介绍：人物选择哪些事实、遗漏哪些？
2. 旧识出现：对方保存了哪个旧版本？
3. 角色冲突：两个身份同时要求忠诚。
4. 公开羞辱：哪种身份判决最伤？
5. 新证据：人物怎样修补或重写故事？
6. 阈值选择：人物愿意失去哪个观众的承认？

## 使用边界

- 不假设存在一个脱离关系和情境的唯一“真实自我”。
- 不把记忆不一致自动写成撒谎或疾病。
- 不以身份标签代替社会制度和具体经历研究。
- 叙事身份用于人物创作，不诊断现实人物的人格或创伤。
