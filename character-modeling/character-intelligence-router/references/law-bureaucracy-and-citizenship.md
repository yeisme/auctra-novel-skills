# 法律、官僚与公民身份知识卡

用于研究规则怎样被定义、记录、执行、协商与规避，以及人物在制度面前拥有什么资格。来源编号见 `social-research-source-ledger.md`。

| 机制 | 事实层 | 创作解释层 | 创作规则层 |
| --- | --- | --- | --- |
| 正式法与实际执行 | 成文规则、执法优先级、地方惯例和资源限制可能不同。[SOC-05][SOC-07] | 人物面对的“法律”往往是具体办事人、程序、证据和等待。 | 分开纸面规则、常态执行、选择性例外和不可挑战红线。 |
| 法律身份 | 年龄、婚姻、国籍、户籍、身份文件、财产和组织成员资格会决定权利与义务。 | 失去文件或资格可让熟悉世界突然不可进入。 | 写人物能签署、继承、移动、作证、工作或获得保护的条件。 |
| 官僚分类 | 机构需要把复杂人生装进表格、类别、案件和优先级。[SEP-01] | 人物可能真实存在却不符合任何可处理类别。 | 设计一个“事实清楚但分类不容纳”的冲突。 |
| 裁量权 | 执行者常在规则范围内拥有解释、排序、宽免或加严空间。 | 小职员、门卫、医生、书记员或平台审核者可以成为关键权力点。 | 明确裁量来源、监督、交换条件和滥用成本。 |
| 程序与等待 | 申请、证明、排队、上诉和复核消耗时间、知识和金钱。 | 强者可买专业帮助，弱者可能因一次缺席失去资格。 | 把制度冲突写成步骤与截止期，不只写“腐败政府”。 |
| 证据与记录 | 制度认可的证据可能与人物知道的真相不同。 | 没有记录的照料、承诺、暴力或身份可能在程序中不存在。 | 同时写发生了什么、能证明什么、谁控制记录。 |
| 处罚与污名 | 社会控制包含正式处罚，也包含名誉、就业、关系和空间排除。[SOC-05] | 处罚结束后，标签仍可继续改变机会。 | 写直接刑罚、附带后果、家庭连带和可否恢复。 |
| 公民实践 | 公民身份不仅是法律标签，也涉及参与、义务、服务、抗议、服从与被承认。 | 人物可法律上属于、文化上被排斥；也可无正式资格却深度承担共同体责任。 | 分开法律资格、实际参与、象征归属和制度待遇。 |
| 非正式中介 | 熟人、经纪、律师、翻译、地方领袖和掮客能帮助穿越制度。 | 中介既提供可达性，也制造债务、收费和信息垄断。 | 写中介掌握的语言、门路、风险和背叛条件。 |
| 申诉与抵抗 | 人物可服从、协商、拖延、规避、上诉、公开、集体行动或退出。 | 抵抗方式取决于证据、盟友、时间和报复风险。 | 给人物至少两个可行但代价不同的制度策略。 |

## 场景问题

- 谁定义“有效证据”？
- 哪个看似低级的岗位控制进入下一步？
- 人物缺的是权利、文件、知识、钱、时间还是被相信？
- 规则的例外对谁开放，代价是什么？
- 一次申诉会不会让人物进入更危险的可见状态？

## 边界

- 不提供现实法律意见；具体法律必须查对应法域与时期的权威来源。
- 不把国家、官僚或执法者写成统一意志。
- 不把违法自动等同邪恶，也不把制度抵抗自动等同正义。
