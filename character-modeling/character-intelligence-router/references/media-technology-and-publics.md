# 媒介、技术与公众知识卡

用于研究信息怎样产生、复制、过滤、保存、监控和形成公众。来源编号见 `social-research-source-ledger.md`。

| 机制 | 事实层 | 创作解释层 | 创作规则层 |
| --- | --- | --- | --- |
| 媒介可供性 | 不同媒介在速度、范围、可复制性、匿名性、同步性和可见性上不同。[SOC-09] | 纸条、广播、群聊和直播会创造不同误会与权力。 | 为关键信息写它能到达谁、多久、能否撤回、谁能证明。 |
| 接入差异 | 设备、网络、识字、技能、语言、费用和制度许可影响参与。 | “所有人都知道”常忽略谁无法接入或不被算法呈现。 | 列出接入者、旁观者、被迫代理者和完全不可见者。 |
| 守门与排序 | 编辑、平台、组织和网络节点决定什么被放大、延迟或删除。 | 影响力不只来自发言，也来自排序与可发现性。 | 写谁能发布、推荐、封禁、存档和改变标题。 |
| 公众与反公众 | 共享媒介和议题会形成想象中的受众、共同体与反对空间。 | 人物可能对真实听众说话，也可能对头脑中的“所有人”表演。 | 明确角色想象的观众与实际观众的差异。 |
| 记录与遗忘 | 技术会改变什么可保存、搜索、复制和遗忘。 | 旧言论、影像或缺失记录可以重写声誉与身份。 | 每个秘密问：谁有副本、元数据、截图、记忆和删除权。 |
| 监控 | 国家、组织、家庭、平台和同伴可通过技术观察和推断。 | 被监控者会改变语言、路线、朋友和自我审查。 | 不只写监控设备；写人物不知道哪些行为会被解释成什么。 |
| 信息过载 | 信息量、速度和冲突会提高筛选与信任成本。 | 人物可能依赖熟人、权威、情绪或身份一致性来过滤。 | 写其默认可信来源和一次来源背叛。 |
| 谣言与修正 | 不确定、重要和情绪化的信息容易在网络中变形；修正传播不必等速。 | 人物可真诚转发错误，也可利用可否认性散播。 | 写谣言满足的需求、传播路径、阻断点和修正的身份代价。 |
| 技术技能与维修 | 使用技术依赖日常维护、基础设施、隐藏劳动和本地知识。 | “高科技”也会因电力、零件、权限或一名技术员失效。 | 为技术场景写故障模式、维修者、备份和绕行路径。 |
| 技术与身体 | 技术改变注意、节奏、姿势、记忆外包和社交距离。 | 人物的设备使用方式可成为关系和身份信号。 | 写设备何时在手、何时必须放下、谁有权要求查看。 |

## 场景问题

- 信息的第一受众、实际受众和被排除者是谁？
- 谁控制可见性而不需要公开发言？
- 一条记录能证明事实，还是只证明某个片段存在？
- 人物在被观察的可能性下如何改变行为？
- 技术故障暴露了哪个被忽略的人或基础设施？

## 边界

- 不提供现实操纵舆论、规避监控、骚扰或极化优化。
- 不把算法写成无主体魔法；标明平台、组织、数据和人的决策。
- 具体技术能力、年代和覆盖范围必须核验。
