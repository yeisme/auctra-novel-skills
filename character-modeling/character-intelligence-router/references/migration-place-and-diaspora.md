# 迁移、地方与离散知识卡

用于研究移动、边界、家乡、侨居、流离、回返和多地关系怎样塑造人物。来源编号见 `social-research-source-ledger.md`。

| 机制 | 事实层 | 创作解释层 | 创作规则层 |
| --- | --- | --- | --- |
| 移动原因组合 | 迁移可能同时涉及工作、家庭、教育、安全、环境、国家政策和个人愿望。[IOM-01][SOC-12] | “自愿/被迫”常不是简单二分，人物可拥有有限选择。 | 写可选路径、不可接受路径和决定发生时的真实信息。 |
| 法律与行政地位 | 身份文件、签证、户籍、庇护、工作许可和居留规则影响移动与权利。 | 同一城市中，人物可生活在不同法律现实。 | 状态只影响资格，不直接决定人格；具体制度交给法律事实包。 |
| 地方依恋 | 家可来自记忆、关系、语言、气候、食物、路线和被承认感。 | 回到地理原点不一定等于回家。 | 写人物最想重遇的地方实践，以及回去后发现已改变的部分。 |
| 多地家庭 | 家庭成员可能跨地区分工照料、收入、身份与未来计划。 | 离开者与留下者会对牺牲、成功和欠债形成不同账本。 | 分别写汇款、照料、决策权、信息延迟和“谁真正承担”。 |
| 侨居网络 | 亲属、同乡、宗教、职业和数字网络可提供工作、住房、翻译与监督。 | 网络既是安全网，也可能加强控制、声誉和义务。 | 写进入网络的担保、价格、互惠和退出成本。 |
| 语言与语码 | 移动会改变可表达的精度、权威、幽默、亲密和自我呈现。 | 人物在一种语言中能命名的自我，在另一种语言中可能不存在同样位置。 | 交给声音语用 specialist 设计转换触发，避免口音刻板化。 |
| 代际差异 | 不同代际对家乡、风险、传统和成功的记忆与利益不同。 | 父母的生存策略可能成为子女的限制，子女的自由可能像背叛。 | 不用“一代传统、二代现代”概括；写各自掌握与失去的资源。 |
| 回返与陌生化 | 回返者可能拥有新资本，也可能失去本地知识和信任。 | “成功归来”会打破旧地位，暴露谁希望他保持原样。 | 写回返者期待被承认的身份与当地人实际承认的身份。 |
| 流离与失去 | 被迫移动可造成关系、财产、记录、墓地、职业和未来想象的断裂。 | 失去不仅是地点，也是行动能力与身份观众。 | 不用创伤景观猎奇；写具体缺失、应对与仍存的能动性。 |
| 边界与通道 | 交通、边境、检查点、费用、季节和中介决定谁能移动。 | 地图上的短距离可因制度和风险变成不可达。 | 把移动写成步骤、等待、文件、身体和关系成本。 |

## 场景问题

- 谁把这次移动称为机会，谁称为抛弃或逃亡？
- 人物在哪种地方或语言中最有能力、最像孩子、最像外人？
- 留下者和离开者怎样记账彼此的牺牲？
- 哪个日常实践比地标更像家？
- 回返后，人物希望恢复的身份还存在吗？

## 边界

- 不把移民、难民、侨民、流离者或跨城务工者混为同一法律与生活经验。
- 不把口音、语言能力或身份文件直接推断为教育、忠诚或智力。
- 具体移动路线、法律状态、人口数据和历史事件必须核验。
