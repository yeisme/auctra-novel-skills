# 动机、需要与价值知识卡

用于区分人物想要什么、为什么想要、什么奖励在维持行动，以及哪些价值使其无法简单改变。来源编号见 `source-ledger.md`。

## 知识卡

| 机制 | 来源事实层 | 创作解释层 | 创作规则层 |
| --- | --- | --- | --- |
| 自主需要 | Self-Determination Theory 将自主视为感到行动出于自我认可，而非等同孤立或拒绝帮助。[INT-02][INT-03] | 一个顺从人物也可能主动选择义务；一个叛逆人物也可能被反抗身份控制。 | 问“这件事是我选择的、不得不做的，还是为了避免羞辱而做的？” |
| 胜任需要 | 人通常需要感到自己能有效行动并发展能力。[INT-02][INT-03] | 反复失败会触发求学、控制、作弊、退缩或贬低目标等不同策略。 | 给人物一个能胜任的领域和一个威胁胜任感的领域，避免全能或全废。 |
| 关系需要 | 关系需要涉及感到被关心、属于某处并与他人连接。[INT-02][INT-03] | “想被需要”可能表现为照料、讨好、控制、牺牲或制造危机。 | 区分想被爱、想有归属、想不可替代和想拥有对方。 |
| 表层目标 | 目标是当前可追逐状态，不等于深层需要。 | 得到目标后仍空虚，可揭示目标与需要错位。 | 每个表层目标写成功条件、时间范围、竞争者和人物愿付代价。 |
| 趋近动机 | 趋近关注获得奖励、接近理想或扩大可能性。 | 同样追求冠军，有人享受精进，有人追求掌声，有人逃离无价值感。 | 禁止只写目标名；必须写人物预期得到的心理和社会状态。 |
| 回避动机 | 回避关注避免惩罚、羞辱、失去、拒绝或身份崩塌。 | 回避动机可产生勤奋、秘密、预防、控制和先发攻击。 | 写出“不行动会发生什么”以及人物相信其概率多大。 |
| 内在奖励 | 活动本身的兴趣、掌握和意义可以维持行动。[INT-02] | 内在投入让人物在无人观看时仍继续。 | 设计一个没有观众、奖励或惩罚的场景，检查人物是否仍做。 |
| 外在奖励 | 金钱、地位、认可、避免处罚和条件性接纳会塑造行动。[INT-02] | 外在奖励不必浅薄；在资源匮乏中它可能关系生存与责任。 | 写明奖励由谁控制、是否可靠、领取它需要表演什么身份。 |
| 价值排序 | 人物往往同时珍视自由、家庭、忠诚、正义、成就、安全等，冲突时才显出排序。 | “重视家庭”只有在家庭与其他价值冲突时才产生戏剧信息。 | 不列价值词云；设计两项都真实重要且不能兼得的选择。 |
| 神圣价值 | 某些价值被人物视为不可交易，尝试定价反而会激怒或羞辱。 | 反派可以误判主角“总有价格”，主角也可能发现自己所谓底线有例外。 | 写出不可交易项、隐性例外、突破后的自我解释和关系后果。 |
| 身份性目标 | 有些目标的价值在于证明“我是怎样的人”。 | 放弃目标可能比失败更像自我死亡。 | 把目标改写为身份句：“如果我做不到，就说明我是……” |
| 承诺与公开成本 | 公开承诺、盟友期待和过去牺牲会强化坚持。 | 人物可能继续错误行动以保护声誉、死者或共同体叙事。 | 列出退出时必须向谁解释，以及谁的牺牲会显得白费。 |
| 目标替代 | 当真正需要难以承认或获得时，人物会追逐可测量替代物。 | 爱的缺口可能被奖杯、追随者、秩序或财富暂时替代。 | 替代目标必须确实提供短期缓解，否则自欺缺少吸引力。 |
| 动机拥挤 | 多个动机可以支持同一行动，也可能互相破坏。 | 救人可以同时来自爱、责任、赎罪、名誉与控制欲。 | 输出动机组合与相对权重，不强求一个“真正原因”。 |

## 动机冲突类型

- `approach–approach`：两个都想要但不能兼得。
- `avoidance–avoidance`：两个都想逃避，必须承担一种损失。
- `approach–avoidance`：同一目标同时带来奖励与威胁。
- `value–need`：价值承诺与基本需要冲突。
- `goal–identity`：有效策略要求人物成为自己鄙视的人。
- `private–public`：私下愿望与公开承诺冲突。
- `short–long`：即时缓解破坏长期目标。
- `self–relationship`：自主与归属、胜任与依赖发生冲突。

## 验证场景阶梯

1. 无人观看：行动是否继续？
2. 奖励取消：人物换目标、抱怨还是发现真正兴趣？
3. 两项价值冲突：人物牺牲什么？
4. 目标成功：满足、空虚还是立刻升级？
5. 身份威胁：人物是否宁愿失败也不接受某种手段？
6. 诱惑：短期奖励怎样让人物合理化第一次让步？

## 使用边界

- 不把全部动机归因于童年、创伤、自卑或性欲。
- 不把内在动机写成高尚、外在动机写成低级。
- 不假设每个角色都需要治疗或完成正向成长。
- 社会资源和制度限制必须与个人动机分开建模。
