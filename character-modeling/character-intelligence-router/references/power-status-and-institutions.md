## 权力卡片

| 机制 | 事实层 | 创作解释层 | 创作规则层 |
| --- | --- | --- | --- |
| 制度 | 制度由持续的角色、规则、惯例、组织和共同认可构成，不只是建筑或法律文本。[SEP-01] | 角色可能服从的不是某个人，而是职位、程序或“大家都这样做”。 | 写出角色、规则、执行者、受益者和例外，而不只写制度名称。 |
| 权力 | 权力是改变他人行动条件或结果的能力，可能来自多种来源。 | 低职位人物可因信息、技能或网络拥有高实际影响。 | 每项权力标注来源、对象、范围、成本、可见度和失效条件。 |
| 权威 | 权威是被认为有权发布要求的地位，与单纯强制不同。 | 同一句命令由合法继承者、篡位者或专家说出，反应不同。 | 问“为什么这个人有资格要求我？”并写出接受与拒绝理由。 |
| 地位 | 地位是群体赋予的尊重、荣誉或排序，不等于可直接命令他人。 | 高地位者可能无法调动资源，却能影响声誉和模仿。 | 用座次、称呼、被打断频率、邀请与羞辱表现地位。 |
| 资源控制 | 金钱、土地、职位、通道、时间、医疗、住房或武力可形成依赖。 | 资源拥有者可以不发命令，只需暗示撤回支持。 | 写出资源替代品、分配规则和撤回后的具体后果。 |
| 信息权力 | 掌握秘密、专业知识、记录、通信入口或解释权会改变决策。 | 书记、秘书、医生、译者、管家或技术人员可能成为隐形中心。 | 标出谁知道、谁能验证、谁能延迟、篡改或选择性透露。 |
| 议程设置 | 权力也表现为决定哪些问题能被讨论、何时讨论、由谁定义。 | 被排除的问题会转入谣言、私下联盟或突然爆发。 | 为重要冲突写一个“谁阻止它进入正式议程”的角色。 |
| 强制与制裁 | 强制依赖惩罚威胁；制裁可以是法律、经济、身体、名誉或关系排除。 | 恐惧能迅速服从，却增加隐瞒、逃跑、串联和破坏。 | 不只写惩罚强度，还写执行成本、误伤和规避路径。 |
| 专业权力 | 稀缺技能和可信判断会让正式上级依赖下属。 | 专家可能在公开场合服从、在关键节点实际否决。 | 设置一个只有专家能识别的风险，并测试其建议被忽略时的后果。 |
| 网络与经纪 | 连接彼此不相通群体的人能控制介绍、翻译、信息和联盟机会。 | 桥接者的力量来自“双方都需要他”，也容易被双方怀疑。 | 画出没有该人物时哪些联系会断裂，以及他如何收费或承担风险。 |
| 赞助与庇护 | 赞助链把资源、忠诚、保护和晋升绑定，常与正式程序并存。 | 角色的成功可能被解释为能力，也可能被解释为靠山。 | 写出恩主、受庇护者、中间人、回报形式和恩主失势后的连锁反应。 |
| 声誉 | 声誉压缩了他人对角色未来行为的预期，能带来合作或排斥。 | 角色会为了维持“可靠、残酷、清廉、神圣”等形象而放弃选项。 | 写出形象带来的资源和限制，并设计一次必须违背形象的危机。 |
| 正当性 | 政治正当性讨论统治或制度为何有权要求服从，常涉及程序、传统、绩效、授权或共同价值。[SEP-02] | 人们可能不喜欢统治者却承认程序，也可能享受利益却拒绝其资格。 | 分别写服从的利益理由和正当性理由，避免混为一谈。 |
| 抵抗 | 弱势者仍可能通过拖延、退出、隐瞒、联盟、讽刺、拒绝合作或公开挑战行动。 | 没有直接胜算的人会改变斗争形式。 | 至少给弱者一个真实但有代价的抵抗选项。 |
| 继承与转移 | 权力依赖的职位、联盟和认可未必能由继承人完整接收。 | 强人离场后，组织可能暴露此前被个人关系遮蔽的裂缝。 | 分拆可继承资产与不可继承信任，设计过渡期守门人。 |

## 权力压力测试

- 资源突然稀缺或被替代。
- 权力来源被公开，幕后人物失去隐蔽性。
- 关键下属集体拖延或拒绝执行。
- 正当性事件出现：败绩、丑闻、程序违规、继承争议。
- 高地位人物被公开羞辱，低地位人物获得象征胜利。
- 外部力量提供新的退出选项或赞助者。

## 使用边界

- 不将权力分析转成现实伤害、胁迫或违法操作建议。
- 制度与正当性概念有争议，具体故事应标明采用的定义。
- 不假设高职位、高地位、高资源和高正当性必然重合。
