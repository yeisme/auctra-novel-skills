## 关系卡片

| 机制 | 事实层 | 创作解释层 | 创作规则层 |
| --- | --- | --- | --- |
| 关系角色 | 亲属、伴侣、朋友、同事等称谓通常附带社会期待，但实际实践会因文化、阶层和家庭而变。[SOC-06] | 同一称谓下，双方可能认定不同义务。 | 分别写双方认为“这个身份应该做什么”，寻找不一致处。 |
| 关系阶段 | 关系会随接触、承诺、危机、分离和修复改变，静态标签不足以预测行为。 | 早期的试探、稳定期的惯例和破裂期的警觉会产生不同对白。 | 每段关系标记当前阶段、上一转折和下一阈值。 |
| 互惠 | 交换不只包含金钱，也包含照料、信息、保护、认可、机会和风险承担。 | “我为你做了这么多”可能源于双方对价值和记账方式不同。 | 建立双方各自的投入账，禁止用作者统一账本代替角色主观账本。 |
| 信任 | 信任是对对方可预测性、善意或能力的风险性判断，不等于喜欢。 | 角色可能信任对方守约，却不信任其同情；也可能相反。 | 分拆能力信任、意图信任、保密信任和危机信任。 |
| 边界 | 边界包含身体、信息、时间、资源、身份和情绪责任；未谈判的边界更易产生冲突。 | 越界者可能认为自己在关心，被越界者却感到被控制。 | 写出允许、默许、禁止、从未谈判四栏，并用一次越界测试。 |
| 依赖与退出 | 退出能力取决于替代资源、社会制裁、身份、照料责任和情感成本。 | 更需要关系的一方不一定更弱，也可能通过不可替代性形成权力。 | 列出双方真实退出选项和退出后第一周、第一年会失去什么。 |
| 亲属义务 | 家庭关系常把照料、继承、婚姻、名誉与代际责任捆绑，但不同社会制度差异很大。[SOC-06] | 角色可能同时爱家人、怨恨义务并依赖家族资源。 | 不用“孝顺/叛逆”概括；分别写情感、资源、名誉和法律义务。 |
| 照料劳动 | 照料既是情感行为，也消耗时间、身体、金钱和机会，且常被视为理所当然。 | 被照料者可能感到亏欠、羞耻、被控制或被爱。 | 记录谁注意需求、谁执行、谁付机会成本、谁获得道德声望。 |
| 债务与人情 | 债务可以是明确契约，也可以是模糊人情；模糊债务更容易被重新解释。 | 施恩者和受恩者对“何时还清”可能永远不同。 | 规定债务的起点、见证者、偿还形式和是否允许拒绝。 |
| 公开与私下脚本 | 社会角色会规定公开表现，而私下关系可能存在完全不同的语言和权力。 | 公共礼貌可能掩盖亲密，也可能掩盖恐惧。 | 为同一对人物写一次公开互动和一次无人旁观互动。 |
| 背叛 | 背叛不是某种固定事件，而是违反了关系中的身份、秘密、忠诚或优先级契约。 | 同一行动可能被一方视为求生，另一方视为不可原谅。 | 明确被违反的隐性契约、是否事先说过、是否存在替代选择。 |
| 修复 | 修复可能需要承认事实、理解伤害、补偿、改变行为、承担公开后果和重建可预测性。 | 道歉不能自动恢复资源、地位或安全。 | 为每次修复设置具体成本和观察期；便宜道歉只能带来有限恢复。 |
| 网络外溢 | 两人关系会受到家庭、朋友、组织和公众评价影响，冲突可能扩散到共同网络。 | 私人背叛可能变成派系事件，和解也可能伤害盟友。 | 列出三名利益相关者：谁希望他们和好、分裂或维持表面关系。 |

## 关系压力序列

1. **低成本交换**：借小物、守时、记住偏好，显示双方默认规则。
2. **信息风险**：分享秘密、承认弱点或替对方保密。
3. **资源竞争**：机会、金钱、时间或第三方注意力不足。
4. **身份冲突**：家庭、组织、伴侣或公众角色要求不同忠诚。
5. **公开代价**：必须在旁观者面前承认、保护或拒绝对方。
6. **不可逆选择**：牺牲退出选项、名誉、自由或第三方利益。

## 使用边界

- 关系卡不是心理诊断工具。
- 亲属与伴侣制度必须按具体时代、法律、经济和文化来源研究。
- 不把控制、跟踪、威胁、隔离和暴力美化成强烈爱情。
- 不假设互惠永远对等；照料与权力可以同时存在。
