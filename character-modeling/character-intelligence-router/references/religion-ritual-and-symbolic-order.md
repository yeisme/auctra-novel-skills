# 宗教、仪式与象征秩序知识卡

用于研究神圣观念、共同实践、机构角色、时间节律和意义系统怎样影响人物。来源编号见 `social-research-source-ledger.md`。

| 机制 | 事实层 | 创作解释层 | 创作规则层 |
| --- | --- | --- | --- |
| 神圣与日常 | 宗教传统常区分或连接神圣、日常、洁净、禁忌与义务。[SOC-10] | 人物可在普通动作中体验宇宙秩序，也可对制度虔诚但私下怀疑。 | 写人物认为不可随意交换、触碰、说出或亵渎的对象。 |
| 信念与实践 | 宗教不仅是命题信念，也包括仪式、身体、时间、饮食、服饰、音乐、空间和共同体。[SOC-10] | 不善于解释教义的人也可能深度生活在实践中。 | 不用一段哲学对白代表信仰；写它怎样安排一天、一年和家庭。 |
| 仪式 | 仪式通过重复、见证、角色和象征标记转变、归属、哀悼或秩序。 | 仪式可真诚、例行、强迫、安慰、排除或政治化。 | 写谁主持、谁观看、谁有资格、谁必须假装、失败如何解释。 |
| 宗教权威 | 权威可来自文本、机构、魅力、传统、学识、血统或社区承认。 | 两个都虔诚的人可因权威来源不同而冲突。 | 分开“谁解释”“谁执行”“谁能宣布例外”。 |
| 转变与归属 | 皈依、退出、复兴、混合实践和代际变化会重排关系。 | 改变信仰可能意味着失去家、语言、婚姻机会或死者联系。 | 写信念变化与共同体成本，不让一次启示解决全部关系。 |
| 苦难解释 | 宗教与哲学系统会提供关于苦难、命运、责任、死亡和希望的解释。 | 同一解释可给一人力量、给另一人羞耻或愤怒。 | 在行动与照料中证明意义立场，不用格言替代。 |
| 罪、羞耻与修复 | 过错可能通过忏悔、补偿、惩罚、净化、宽恕或重新纳入处理。 | 人物与机构可对“何时算修复”有不同答案。 | 写修复的见证者、具体成本和仍不可恢复之物。 |
| 宗教与权力 | 宗教机构可提供教育、救济、身份与抵抗，也可能参与地位和排除。 | 信仰、组织利益与国家关系不能合并成一个动机。 | 分开个人信念、地方共同体、机构政策和政治联盟。 |
| 多重传统 | 人物可能同时继承、实践或重新解释多个传统。 | 表面“不一致”可能是家庭史、地方实践或情境身份。 | 不以纯化标准替角色判断其是否“真正信”。 |
| 怀疑与沉默 | 怀疑、不可言说经验和策略性沉默也是宗教生活的一部分。 | 人物可继续仪式以爱家人、守承诺或等待答案。 | 写他不能对谁说怀疑，以及继续实践获得与失去什么。 |

## 场景问题

- 哪个时间、地点或物件改变了人物可做的事？
- 谁拥有解释传统的权威，谁只有执行义务？
- 仪式失败、缺席或被打断会被怎样理解？
- 人物的私人信念、家庭实践与机构立场有何差异？
- 宽恕是否恢复关系、资格、名誉和自我故事中的同一部分？

## 边界

- 不把宗教写成迷信、统一教条或自动道德来源。
- 具体传统必须使用该传统的一手、学术或社区权威来源。
- 不虚构真实群体的敏感仪式细节来制造猎奇。
