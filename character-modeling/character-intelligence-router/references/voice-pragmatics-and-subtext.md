# 声音、语用与潜台词知识卡

用于设计人物如何借语言完成行动，而不仅是怎样“说得有特色”。来源编号见 `source-ledger.md`。

## 语用回路

```text
communicative goal
  -> relationship and power position
  -> speech act
  -> literal wording
  -> implicature / silence
  -> listener inference
  -> response and relationship update
```

## 知识卡

| 机制 | 来源事实层 | 创作解释层 | 创作规则层 |
| --- | --- | --- | --- |
| 言语行为 | 说话可以同时是在陈述、请求、承诺、威胁、允许、命名或宣判。[INT-10] | “你今天很晚”可是在报告、责备、试探、关心或发出最后通牒。 | 每句承重对白先写人物试图完成的行动，再写字面内容。 |
| 会话含意 | 听者会结合语境、共同知识和合作预期推断未明说内容。[INT-09][INT-11] | 潜台词不是把真话藏起来，而是让对方有理由推断另一层行动。 | 明确双方共享什么信息；没有共享前提的暗示只是作者谜语。 |
| 直接与间接 | 人物可直接提出，也可借问题、暗示、故事、第三方或沉默表达。 | 间接性可能来自礼貌、恐惧、地位、操控、文化脚本或享受游戏。 | 同一人物在对上、对下、亲密和陌生场合使用不同直接度。 |
| 面子与礼貌 | 沟通会管理自我形象、对方尊严、关系距离和公开秩序。[INT-09] | 礼貌可以是真尊重，也可以是冷酷的距离、等级表演或可否认威胁。 | 不把礼貌词数量当礼貌；检查它保护谁的面子、牺牲谁的自主。 |
| 称谓与指示 | 名字、头衔、代词、敬语和“我们/他们”会定位关系与群体边界。 | 一次称谓改变可比表白更清楚地显示亲近、疏离或夺权。 | 为重要关系定义平时称谓、公开称谓、冲突称谓和修复称谓。 |
| 轮次与打断 | 谁能开始、结束、打断、沉默或要求解释，反映关系和制度权力。 | 弱势人物也可通过不回答、误解、拖延或让对方多说取得局部控制。 | 对白修订时标注每轮谁夺得议题、信息或情绪控制。 |
| 回避与可否认性 | 模糊、被动语态、无主句、玩笑和引用他人可以降低承诺。 | 人物可能让对方“自己听懂”，从而避免责任。 | 每次暗示写出人物希望获得的收益和拒绝承认的责任。 |
| 沉默 | 沉默可以是无话、拒绝、服从、惩罚、保护、计算或无法表达。 | 沉默的意义来自谁期待回答、谁能承受等待。 | 不写“他沉默了”就结束；写对方如何解释并因此做了什么。 |
| 修正与自我修正 | 停顿、改词、重复和撤回显示人物监控风险与身份。 | “我爱——我是说，我担心你”可暴露禁语和关系边界。 | 修正必须服务目标或风险，不把口吃当廉价个性装饰。 |
| 词汇与隐喻 | 职业、地域、阶层、阅读、信仰和经验塑造可用词汇与比喻。 | 声音来自人物如何分类世界，不是口头禅集合。 | 建立人物常用概念域、禁用词、误用词和只对某人使用的词。 |
| 信息包装 | 同一事实可先给结论、过程、情绪、例外或背景。 | 包装顺序揭示人物认为听者需要什么，以及自己想隐藏什么。 | 比较人物在好消息、坏消息和请求帮助时的首句。 |
| 语码转换 | 人物会随语言、方言、阶层、职业、场合和群体改变表达。 | 转换可表示归属、伪装、礼貌、羞耻、权力或回家。 | 指明触发条件和转换代价，不把方言当笑料或固定人格。 |
| 对话修复 | 误听、误解和冒犯后，人物可澄清、重述、否认、升级或假装没发生。 | 修复方式比误会本身更能体现关系安全。 | 为每对重要关系定义“谁先修复、如何修复、什么不能修复”。 |
| 身体—声音一致 | 音量、速度、呼吸、视线、距离和动作会支持或反驳字面语言。 | 真诚不一定身体一致；人物也可训练表演。 | 为承重对白写一个支持字面的身体信号和一个泄露另一层目标的信号。 |

## 声音指纹

声音至少包含：

```text
attention vocabulary
+ sentence architecture
+ certainty language
+ speech-act preferences
+ relationship positioning
+ what remains unsaid
+ metaphor source
+ repair behavior
+ code-switch triggers
+ body-rhythm alignment
```

## 潜台词验证

一段潜台词成立，至少满足：

1. 人物有不能直说或不愿直说的原因。
2. 双方共享足够前提，让推断可发生。
3. 字面层本身仍像真实人物会说的话。
4. 对方的回应显示其理解、误解或拒绝理解。
5. 交流改变信息、权力、关系或行动状态。

## 使用边界

- 不把口头禅、方言拼写或怪异标点当完整声音。
- 不用文化和阶层刻板印象生成语言。
- 不复制受版权保护角色的大量原对白来“仿声”。
- specialist 只产出规则和候选短句，完整场景交给对应 writer。
