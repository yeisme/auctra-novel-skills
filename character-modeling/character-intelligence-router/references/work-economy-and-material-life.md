# 工作、经济与物质生活知识卡

用于研究人物怎样获得生计、分配时间、承担风险、使用物件并进入交换网络。来源编号见 `social-research-source-ledger.md`。

| 机制 | 事实层 | 创作解释层 | 创作规则层 |
| --- | --- | --- | --- |
| 生计组合 | 家庭与个人的生计可能同时依赖工资、土地、手艺、照料、赠与、债务、补贴或非正式交换。[SOC-11] | 人物的“职业”可能只占真实生存系统的一部分。 | 列出现金、实物、关系和制度四类来源，以及任何一项中断后的第一周。 |
| 劳动分工 | 工作会按技能、身份、性别、年龄、阶层和组织规则分配，并产生不同声望与风险。[SOC-11][SEP-04] | 最重要的劳动未必被命名、支付或看见。 | 记录谁执行、谁安排、谁承担身体成本、谁获得功劳。 |
| 工作控制 | 人物对任务、时间、节奏、工具和结果的控制程度不同。 | 同一职位在自主性、监控和可替代性上可完全不同。 | 不用职称推断生活；写出谁能说“不”、谁能改流程、谁随时可被替换。 |
| 非正式经济 | 许多交换发生在正式合同、税收或组织记录之外。 | 人情、黑市、家庭作坊和临时工会制造隐性依赖与风险。 | 写出交易靠何种信任、见证、暴力或声誉执行。 |
| 债务与信用 | 债务连接未来劳动、关系、法律和道德义务。 | 欠钱、欠人情和欠家族可能采用不同记账方式，却同时束缚选择。 | 分开本金、利息、声誉、羞耻和拒绝偿还的制裁。 |
| 物质基础设施 | 住房、交通、能源、水、通信和储存决定可执行的行动。 | 很多“性格”差异其实是距离、拥挤、隐私和工具可得性的差异。 | 关键场景先问人物到达、等待、保存、隐藏和联系是否物理可行。 |
| 消费与身份 | 物品可表达资格、品味、体面、归属和未来想象。 | 角色可能为一件物品支付超出功能价值的身份成本。 | 写物品的获得渠道、维护成本、识货观众和被识破风险。 |
| 时间贫困 | 多重劳动、照料、通勤和排队会压缩可自由支配时间。 | “没有计划”可能来自没有稳定时段，而非缺乏责任感。 | 为人物做一日时间账，找出谁拥有连续时间、谁只拥有碎片时间。 |
| 风险转移 | 组织和强者可能把伤病、价格、失业、失败或法律风险转给弱者。 | 表面自由职业或机会可能意味着个人承担全部波动。 | 每项收益写明谁承担最坏情况，谁拥有退出与保险。 |
| 经济冲击 | 失业、通胀、灾害、战争、自动化和政策变化会重排家庭与组织关系。[SOC-11] | 危机不是背景音，它会改变婚姻、迁移、犯罪、互助与政治态度。 | 写冲击前的缓冲、首先出售的东西、最后不愿出售的东西。 |

## 场景问题

- 人物一天中哪些时间属于自己？
- 其收入是否可预测，谁可以延迟或扣留？
- 哪项看不见的劳动维持了其他人的自由？
- 一件物品为何代表“我配得上”或“我们还没失败”？
- 如果一周无法工作，人物首先向谁求助、隐瞒或撒谎？

## 边界

- 不用现代工资劳动默认解释所有时代。
- 不把贫穷、富裕、职业或消费直接推断为人格。
- 具体价格、制度与生活标准必须按时空来源研究。
